# NMC Registered

UK based application for Nursing Homes and Medical Professionals

## Tech Stack

### Backend

- Node.js
- TypeScript
- Express

### Database

- PostgreSQL
- Prisma ORM

### Caching and Messaging

- Redis

### Payment Gateways

- Stripe
- Paypal

### Validation

- Zod

### Tools

- Eslint
- Prettier

# Clone repository

git clone https://github.com/your-username/your-repo.git

# Navigate to project

cd your-repo

# Install dependencies

yarn install

# Development

yarn dev

# Build

yarn build

# Start production server

yarn start
